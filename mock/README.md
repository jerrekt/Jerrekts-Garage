# v1 mock

Static click-through of the merged v1 plan (Mnemosyne `projects/garage-site-options.md`). No backend: `data.js` stands in for the API. Visits and raw text are the real E36 log; maintenance intervals and work types are placeholders until confirmed; repair-story fields that were never recorded are shown as missing, not filled in.

Open `index.html` via any static server (`python3 -m http.server`) and use the tabs: Dashboard, Quick Log, History, Repair stories, Public page.
