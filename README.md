# Jerrekt's Garage

Maintenance site for my cars under Jerman Engineering. Pick a car, click a system, see what's been done and what's due.

Static HTML plus JSON per car in `data/`. No build step. Knowledge and decisions live in Mnemosyne (`projects/bmw-fleet.md`, `projects/bmw-fleet-notes.md`); this repo holds code and data only.

Version: v0.1.0 (preview, not deployed)
